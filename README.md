# Evaluation Dash

## Description
Application Dash multipages permettant :
- de comparer les quantités vendues par région
- d’afficher les données sous forme de tableau filtrable
- de consulter une aide en ligne en Markdown

## Structure du projet
- `app.py` : point d’entrée de l’application
- `pages/page1.py` : page de comparaison des régions
- `pages/page2.py` : page d’affichage des données
- `pages/page3.py` : page d’aide en ligne
- `datas/` : fichiers de données et fichiers markdown
- `assets/` : ressources statiques
